# QA Final Integrator — Urban Scooter

Proyecto final integrador del bootcamp de QA Automation (TripleTen, Sprint 10). Este repositorio demuestra la automatización de pruebas de **API** (requests + pytest) y **UI** (Selenium + POM) sobre la aplicación Urban Scooter, junto con la documentación de bugs encontrados y los artefactos de prueba.

## 🎯 Objetivo

Integrar en un solo proyecto las habilidades adquiridas durante los 9 sprints del bootcamp:
- Diseño de casos de prueba con clases de equivalencia y valores límite.
- Automatización de API con `pytest` y `requests`.
- Automatización de UI con `Selenium` y `Page Object Model`.
- Documentación profesional de bugs (Jira + GitHub Issues).
- Buenas prácticas: `.gitignore`, `README`, estructura limpia.

## 🛠️ Tecnologías

- **Python 3.13**
- **pytest 9.2.0**
- **requests 2.34.2**
- **Selenium 4.52.0** (UI)
- **Git / GitHub**
- **Jira** (gestión de bugs)
- **Android Studio** (emulador para app móvil)
